## Document Authority Rules

1. **`ReadEase Database Schema — v2.0.txt`** is the single source of truth for database structure, ERD, DFD, and design rationale. Any conflicting information in other files is superseded by v2.0.

2. **`ReadEase Capstone 2 Documentation Package.docx`** is the authoritative source for requirements (FRs, NFRs), bug inventory, ISO 25010 instrument, and limitations.

3. **The `.docx` file version of the schema is deprecated** — it has rendering issues and should not be distributed. Use the `.txt` version.

4. **This index is authoritative for section-to-file mapping.** If in doubt, look here first.
